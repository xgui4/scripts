# Xgui4's Scripts

This repo containts scripts that do not requires their own repos.
Note some scripts can be moved to their owns repo if i extend them
or that they become big enought to have their own repo.

## Repo source tree

`data/` contains data for the virtual-rms.sh scripts
`packages/` contains PKGBUILD or other package/distributions scripts
`src/` where the scripts are located
`src/inits-scripts` contains open-rc or other init systems init scripts
